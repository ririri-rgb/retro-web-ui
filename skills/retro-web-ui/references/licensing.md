# Licensing and asset policy

The bundled implementation is original CSS and standard-library code under MIT. It intentionally contains no extracted Windows assets, Microsoft fonts, system icons, DLL resources, wallpapers, sounds, or copied screenshots.

Names such as Windows are used only to describe compatibility/style targets. Do not imply Microsoft endorsement. Keep repository branding independent.

Before adding a dependency or reference implementation:

1. Verify the license in its canonical repository and the exact version.
2. Check redistribution, attribution, notice, font, icon, image, and trademark terms separately.
3. Prefer dependencies compatible with MIT distribution; record notices in `THIRD_PARTY_NOTICES.md`.
4. Do not assume an MIT code license covers bundled proprietary fonts or assets.
5. Link to historical screenshots for research instead of redistributing them unless their license explicitly permits inclusion.

98.css, XP.css, 7.css, React95, and similar projects can inform interoperability research, but this skill does not vendor their code. If a target application already uses one, preserve its license and notices.
