# Security policy

## Supported versions

Security fixes are applied to the latest released minor version.

## Reporting

Do not disclose exploit details or credentials in a public issue. After publication, use the repository's **Security → Advisories → Report a vulnerability** form when enabled. If private reporting is unavailable, open a minimal issue asking the maintainers for a private contact method without including sensitive details.

The helper scripts are local tools and intentionally avoid network access, subprocess execution of target-project commands, source excerpt collection, and automatic source rewriting. Review any future change that expands those boundaries.
